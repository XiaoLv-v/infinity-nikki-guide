# 无限暖暖攻略站 ✨

> Infinity Nikki 中文攻略站 — 自动部署到 GitHub Pages

## 功能

- ⭐ 奇想星收集清单（本地保存进度）
- 👗 服装图鉴（按类型筛选）
- 🎯 穿搭挑战攻略
- 📬 邮件订阅
- ✅ 响应式手机适配

## 技术栈

纯 HTML + CSS + JavaScript，零依赖，托管在 GitHub Pages。

## 部署方式

1. Fork/Clone 此仓库
2. 在 GitHub 仓库 Settings → Pages 中启用
3. 选择 main 分支根目录
4. 访问 `https://<用户名>.github.io/infinity-nikki-guide/`

## 添加 Google AdSense

在 `index.html` 中加入 AdSense 代码即可启用广告收入。
