💧 什么是灵感露珠？

灵感露珠（Dewdrops of Inspiration）是无限暖暖中的特殊收集物，与奇想星不同，灵感露珠更隐蔽且数量更多。收集灵感露珠可以在灵感商店兑换限定服装、饰品和制作材料。

📊 各区域分布概览

  • 愿望之乡 — 约80个，分布在广场、花园和建筑周边
  • 花愿镇 — 约60个，集中在镇内、后山和河岸区域
  • 微风原野 — 约100个，散布在广阔原野各处
  • 洞穴/秘境区域 — 约30个，需要探索隐藏区域

当前版本总计约270个灵感露珠可供收集。

🗺️ 最佳收集路线（30分钟版）

路线一：愿望之乡 + 花愿镇（约15分钟）

  1. 起点：中央广场 → 绕广场一周收集(约15个)
  2. 向东至钟楼 → 沿途收集(约10个)
  3. 向南至教堂花园 → 密集区域(约20个)
  4. 传送至花愿镇 → 镇内集市周边(约12个)
  5. 花愿镇后山 → 上山路线(约18个)
  6. 河岸沿线 → 平行走一遍(约10个)

路线二：微风原野（约15分钟）

  1. 传送至微风原野入口 → 沿主路收集(约15个)
  2. 山坡往上至湖边 → 绕湖收集(约20个)
  3. 遗迹区域 → 注意隐蔽角落(约18个)
  4. 断桥至大树 → 高处利用飞行能力(约15个)
  5. 瀑布区域 → 终点的密集区域(约12个)

💡 收集技巧

  1. 开启音效 — 灵感露珠会发出轻微的闪烁声，靠近时声音变大
  2. 使用觅踪能力 — 解锁后可扫描周围区域的露珠位置
  3. 注意视觉提示 — 露珠是淡蓝色的发光小点，在暗处更明显
  4. 别漏了高处 — 部分露珠在屋顶、树梢等高处，需要跳跃或飞行
  5. 洞穴探索 — 每个洞穴内通常有3-5个露珠，值得专门跑一趟
  6. 利用传送点 — 每次上线花10分钟跑一条路线，一周即可全收集

🎁 灵感商店兑换推荐

收集到的灵感露珠可以在灵感商店兑换以下物品（按优先级排序）：

  1. 限定套装（优先） — 灵感商店的限定套装通常需要200+露珠

  5. 金币 — 最后有剩余再换
